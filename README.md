# BloodBridge

A web application to help users find nearby blood banks and check blood type availability.

## Features

- Search for blood banks by location (city name or ZIP code)
- View available blood types and quantities
- Filter blood banks by blood type
- Real-time availability updates
- Responsive design for all devices

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Styling: CSS3

## Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/harishperni/BloodBridge.git
cd BloodBridge
```

2. Install dependencies:
```bash
npm install
```

3. Create a .env file in the root directory with the following variables:
```
MONGODB_URI=your_mongodb_uri
PORT=5001
```

4. Start the development server:
```bash
npm run dev
```

5. Open http://localhost:3000 in your browser
